Zoho Creator Client Portal — Trade Conseils et Services

Custom Zoho Creator application built from scratch for a service-provider portal: providers log in and only see interventions assigned to or requested by them, filtered by their login email (zoho.loginuserid) at the report level. Full lifecycle: available interventions -> request -> pending approval -> accepted -> closed, with a dashboard and satisfaction tracking.

Dashboard — KPIs (available / pending / accepted / closed) and a 30-day closed-interventions chart. See 1.png

Request form — provider submits an intervention request with trade type, address, and description. See 2.png

Available interventions — filterable list by trade (locksmith, electricity, plumbing, general work), each provider only sees openings relevant to their scope. See 3.png

Pending requests — provider's own submitted requests, editable date proposal. See 4.png

Closed interventions history — full record of completed work with dates and satisfaction rating. See 6.png

Tech stack

Zoho Creator, Deluge, report-level filtering with zoho.loginuserid for per-user data isolation, Zoho CRM, Zoho Books, REST APIs, Webhooks, OAuth2, HTML/CSS/JavaScript
